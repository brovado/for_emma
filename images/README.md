# Emma's Game Images

Put the reveal pictures for the game in this folder.

Recommended formats: `.jpg`, `.jpeg`, `.png`, or `.webp`.

Suggested names:
- `unicorn-1.jpg`
- `princess-1.jpg`
- `fairy-1.jpg`
- `castle-1.jpg`

The game automatically uses supported image files listed in `script.js`. Keep the images bright, simple, and easy for a young child to recognize.
